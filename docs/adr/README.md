# Architecture Decision Records

Short records of significant decisions already made and implemented in
this codebase — not a wishlist (that's `docs/v2/`), a record of *why*
things are the way they are, for the next person who wonders "why is it
built like this?" and would otherwise have to reverse-engineer it from
code comments scattered across several files.

Add a new one (`00N-title.md`, numbered sequentially) whenever a decision
is made that a future engineer would otherwise have to guess at or
accidentally undo. Format: Context, Decision, Consequences — keep each
one short enough to actually get read.
